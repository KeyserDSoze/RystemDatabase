# @rystemdb/client (TypeScript)

Planned Node.js SDK for native framed RSWP v1 binary RPC, tracked by [#28](https://github.com/KeyserDSoze/RystemDatabase/issues/28).

Initial target: a strict frame codec with the same golden octets as Rust and C#, then a typed TLS client with AbortSignal, timeouts and request correlation. BigInt and byte arrays need precise wire conversions.

**Status: scaffold only — not published or connected yet.** This is distinct from the `npm/cli` binary installer.
